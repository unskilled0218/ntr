## Command

- Clean up docs
  - Remove unnecessary
- Rewrite short and easy to understand
- Remove todo.txt related completely

## Goal

Simplify the parent, app, and server documentation. Remove unnecessary or duplicate content and todo.txt-specific guides, references, and examples from maintained documentation. Keep the remaining instructions short, clear, linked correctly, and accurate about current app/server behavior. This is documentation cleanup, not removal of runtime backends or user data.

## Suggestions

Keep READMEs brief and use dedicated topic pages. Preserve essential setup, security, signing, release, and recovery guidance. Leave historical task archives and release records unchanged; fix maintained links affected by deleted guides without rewriting history. Do not modify `todo.md`, implementation code, or unrelated app changes.
