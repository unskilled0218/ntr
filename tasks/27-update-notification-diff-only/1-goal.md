# Diff-only update notification

- [Diff-only update notification](#diff-only-update-notification)
  - [command](#command)
  - [goal](#goal)

## command

Display diff only without any other messages on notify update.

## goal

Simplify remote-update notifications so the diff is the only informational content. Remove surrounding notification headings, explanatory text, summaries, and verbose preview messages. Keep the controls needed to inspect changes and approve or dismiss the update, while preserving accessibility, bounded previews, and existing update safety.
